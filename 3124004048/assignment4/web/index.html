● 外部 API 调用

Open-Meteo 天气服务（地理编码 + 预报），无需 API Key，失败自动降级为可读提示。

● 前端界面

FastAPI + 原生 HTML/CSS/JS，SSE 流式对话，工具调用过程实时可视化。
